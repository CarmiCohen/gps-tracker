## Strategic Simplification Ideas

### SIMP-NOV23.9-S1 - Drop the prefix fallback
Since Nov23.9 the service start, stop and Home Points events carry an `EventEntry.kind`; `isOfKind` in `EventLog.kt` still falls back to the message's start for an event without a kind. Once both phones have run Nov23.9 or later for 7 days, the fallback (and the prefix use in `stopReason`) could go, with the tests of the old wording.

### SIMP-NOV22.8-S1 - Fewer rows while nobody watches
**Low priority (user decision 2026-11-25; was very low, 2026-11-22).** Since Nov22.8 the relay no longer sends rows back to the Sensor, so with no Monitor connected the rows reach nobody; one row per 10 s while the viewer status says no Monitor would cut the Sensor's mobile data (about 25 MB a day at one row a second) to a tenth, at the price of a coarser stored trail and a Sensor that depends on the viewer status.

### SIMP-NOV22.8-S2 - The Monitor's foreground state
**Low priority (user decision 2026-11-25; was very low, 2026-11-22).** The Monitor keeps its relay connection in the background too (O122), so "a Monitor is connected" does not mean someone is looking. A Monitor -> Sensor message for foreground and background would let the Sensor send its rows faster or slower by it (two Monitors, lost connections and a killed Monitor to be handled).

### SIMP-NOV19.6-S1 - Compose's own text fitting
Since Nov19.6 the HUD data keeps to one line through a private `OneLineFitText` in `HudStatusBar.kt` that measures the text with `rememberTextMeasurer` and steps the font down. Compose BOM 2023.10.01 has no `autoSize`; once the BOM is raised (with the Kotlin upgrade of ISSUE-NOV10.4-O72), `BasicText(autoSize = TextAutoSize.StepBased(6.sp, 9.sp))` would replace it. **Blocked by O72 (found 2026-11-23): `TextAutoSize` needs Compose foundation 1.8 (BOM 2025.04+), so Kotlin 2.x, the Compose compiler plugin, KSP, AGP and compileSdk come first.**

### SIMP-NOV9.3-S1 - R8 for the release builds
Low priority (user decision 2026-11-23; explained 2026-11-25, the user took another item: best after O72, which changes Hilt's and Room's generated code, with the relay live for the socket and push checks).
