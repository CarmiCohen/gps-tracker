# Issue #325: Authoritative Spatial Anchoring

## 🎯 Status: Resolved (Historical)
**Category**: Engine / Data Integrity

---

## 📝 Description
Violation events were being recorded with inconsistent coordinates when multiple filters (IMM/EMA) were active. This task established `ViolationProcessor` as the central authority for anchoring a violation to a specific spatial point.

## 🛠️ Resolution
- Defined the `SpatialAnchor` interface to standardize location metadata.
- Centralized coordinate capture for all alert types within `ViolationProcessor.kt`.
- Ensured that forensic markers use the exact "optimized" point generated by the engine at the moment of breach.
